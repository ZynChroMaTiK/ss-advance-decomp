# Earlier Rome pickup artwork

This folder keeps the golden laurel artwork tried earlier in development. **The game now
uses the original golden ankh in both Egypt and Rome.** The game doesn’t use
these laurel images anymore.

**To play, you’ll need your own European version of the Serious Sam Advance ROM** at `orig/SSA.gba`. Other regional versions won’t work. No ROM is included.

- `laurel-20x34.png` and `laurel-10x17.png`: the old replacement sprites.
- `source.png` and `prompt.txt`: the generated source artwork and its prompt.
- `manifest.json`: image details and file checksums.

See [the development notes](DEVELOPMENT.md) for how these images were made
and tested.
