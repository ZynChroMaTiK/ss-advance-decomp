# Earlier Rome pickup artwork

This folder keeps an earlier golden laurel design for reference. **The game now
uses the original golden ankh in both Egypt and Rome.** The laurel is no longer
used by either renderer.

- `laurel-20x34.png` and `laurel-10x17.png`: the former replacement sprites.
- `source.png` and `prompt.txt`: the generated source artwork and its prompt.
- `manifest.json`: image details and file checksums.

See [the development notes](DEVELOPMENT.md) for how the former artwork was made
and tested.
