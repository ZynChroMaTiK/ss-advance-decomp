# Serious Sam Advance v0.8.0 Alpha 4

Alpha 4 adds optional lighting and shadows, richer water and surface details,
original-asset mipmapping, mouse sensitivity controls, and faster rendering.
All twelve campaign levels remain available.

## Play

**You need your own European Serious Sam Advance ROM. It is not included.**

1. Extract `ss-advance-v0.8.0-alpha.4-windows-x64.zip` into a writable folder.
2. Put your ROM at `orig/SSA.gba`.
3. Run `play-native.cmd`. No compiler, Vulkan SDK or emulator is needed.

Keep `save.dat`, `settings.dat` and `scores.dat` when updating. Existing settings,
unlocks and scores are retained. The supported ROM's SHA-1 is
`4ff48d8c18b70a5184758f1917343ae85a70858e`.

## New since Alpha 3

- **Water and surface details:** animated tiled shoreline waves, ripples and
  white glints, plus connecting floor/ceiling edge details. Reflections fade
  toward the water's own color; GBA reflections no longer use color dithering.
  Backgrounds and godrays appear in reflections again.
- **Godrays:** optional short light shafts beneath sky openings, using the same
  textured, world-texel dithered gradient in GBA, Software and Vulkan.
- **Sprite shadows:** optional size-scaled billboard shadows for players, enemies
  and items, drawn behind their subjects. Death sprites and explosion effects
  are no longer cut off by floor geometry; wall and doorway occlusion remains.
- **Mipmapping:** the original lower-resolution texture and sprite assets are
  used at distance, including reflections. Enabled for fresh settings and
  always On in GBA mode; existing native preferences migrate without changing
  their previous appearance.
- **Controls and menus:** one mouse sensitivity slider controls both axes,
  from 10% to 300%, default 100%, above Field of View. Graphics now holds
  Mipmapping, Surface decals, Water reflections, Godrays and Sprite shadows.
  The Classic HUD notification now reads “Analysing”.
- **Combat and input:** healthy enemies choose between the player and converted
  enemies by distance. The extra half-melee/double-other damage modifiers
  between enemies have been removed. Fire clicks during reloads or button
  interactions are discarded instead of firing later.
- **Rendering performance:** cached surface sampling and Vulkan texture uploads,
  shared sprite clipping preparation and streamlined reflections. Three paired
  1080p runs on an RTX 4060 Laptop GPU measured 28–32% less render time in
  reflective water scenes and about 20% less with godrays, with identical output.
  These are isolated rendering measurements, not gameplay FPS guarantees.

Vulkan remains the default on supported systems, with automatic Software
fallback. Existing renderer choices are preserved. Surface decals, Water
reflections, Godrays and Sprite shadows are independent Graphics options, Off by
default. Jump, Automap, Alternate weapons and Weapon bobbing also default Off;
third-person, in-game NETRICSA and vertical aim default On. Saved choices win.

## Controls

| Control | Action |
| --- | --- |
| WASD | Move |
| Mouse / left-click | Look / fire |
| E | Use |
| 1–0 / mouse wheel | Select weapon |
| Q | Previous weapon |
| R | Reload Colts with Alternate weapons enabled |
| Space | Jump, when enabled in Extras |
| H | Toggle third-person, when enabled |
| Tab / N | Toggle NETRICSA |
| M | Toggle automap, when enabled |
| + / − / mouse wheel in automap | Zoom |
| Esc / P | Pause / resume |
| F11 | Toggle fullscreen / windowed |

Original, optional SoundFont and Windows MIDI music are selectable when available.
SoundFont banks are not included; see `soundfonts/README.md` for setup.

## Known limitations and validation

This is still an alpha. Multiplayer is not playable and original-game parity
is still being refined. Saves retain unlocks, settings and scores, not a
mid-level position. Vulkan still uses CPU composition and frame readback;
full-resolution reflections remain demanding.

The Windows build, eleven focused regression suites, Vulkan validation,
sanitizer checks and settings/audio tests pass. Before/after rendering hashes
match in eight Vulkan and eight Software scenes; 39 menu captures are unchanged.
Release checks also cover the packaged launch and website. All twelve campaign
levels remain available for manual playtesting; no new full playthrough is claimed.
