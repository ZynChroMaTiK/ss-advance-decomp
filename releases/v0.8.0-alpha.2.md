# Serious Sam Advance v0.8.0 Alpha 2

The second alpha adds a usable Classic HUD, an optional automap, saved high
scores, and more visual extras, alongside gameplay, audio and reliability fixes.
All twelve campaign levels remain available.

## Play

**You need your own European Serious Sam Advance ROM. It is not included.**

1. Extract `ss-advance-v0.8.0-alpha.2-windows-x64.zip` into a writable folder.
2. Put your ROM at `orig/SSA.gba`.
3. Run `play-native.cmd`. No compiler or emulator is needed.

Keep `save.dat`, `settings.dat` and `scores.dat` when updating. Existing settings
are retained. The supported ROM's SHA-1 is
`4ff48d8c18b70a5184758f1917343ae85a70858e`.

## New since Alpha 1

- **Classic HUD:** choose Original or Classic in Extras. Classic includes health,
  armor, ammo meters, a weapon selector, high score, timer, boss icon/bar and
  unread NETRICSA notifications. Both renderers support it.
- **Automap:** enable it in Extras, then press M. Zoom with +/− or the mouse wheel.
- **Scores and lives:** qualifying runs offer keyboard name entry and saved high
  scores. Death consumes a life and retries the level automatically; the last
  life leads to Game Over before returning to the menu.
- **Visual extras:** optional weapon bobbing, subtle floor/ceiling stain tiles,
  animated water glints/ripples and water reflections. These default to Off.
  The blue floors in the Forum of Mars and Caesar's Palace are treated as dry.
- **Display controls:** F11 toggles borderless fullscreen/windowed mode. Software
  rendering offers Native or 3:2 aspect ratio; GBA mode stays at 3:2.
- **NETRICSA:** enemy dossiers unlock on kills; starting equipment is already
  known. Opening the guide selects the newest unread entry. In-game NETRICSA
  preserves the music track and playback position.
- **Gameplay fixes:** ammo can be collected before its weapon, duplicate weapons
  supply ammo, and R manually reloads Colts with Alternate weapons enabled.
  Improved weapon/HUD feedback, transitions, pickup sound handling and menus.
- **Reliability and performance:** safer save-error handling, synchronized audio
  status, shared decal data and renderer optimizations. Extras now shows every
  option on one page, one grid tile per row.

Jump, Alternate weapons, Automap, Weapon bobbing, Surface decals and Water
reflections default to Off. Third-person and in-game NETRICSA default to On;
the HUD defaults to Original. Existing saved choices take precedence.

## Controls

| Control | Action |
| --- | --- |
| WASD | Move |
| Mouse / left-click | Look / fire |
| E | Use |
| 1–0 / mouse wheel | Select weapon |
| Q | Previous weapon |
| R | Reload Colts with Alternate weapons enabled |
| Space | Jump, when enabled in Extras |
| H | Toggle third-person, when enabled |
| Tab / N | Toggle NETRICSA |
| M | Toggle automap, when enabled |
| + / − / mouse wheel in automap | Zoom |
| Esc / P | Pause / resume |
| F11 | Toggle fullscreen / windowed |

Original, optional SoundFont and Windows MIDI music remain selectable when
available. Music and effects have separate volume controls. SoundFont banks are
not included; see `soundfonts/README.md` for setup.

## Known limitations and validation

This is still an alpha. Multiplayer is not playable, and original-game parity
is still being refined. Saves retain unlocks, settings and scores, not a
mid-level position. All campaign levels are available for manual playtesting;
this release does not claim a new automated campaign completion run.

The release build is checked with focused native rendering, HUD, settings,
save/audio and frontend tests, plus website checks and packaged launch tests.
