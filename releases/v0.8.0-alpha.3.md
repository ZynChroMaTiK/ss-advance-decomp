# Serious Sam Advance v0.8.0 Alpha 3

Alpha 3 adds Vulkan hardware rendering, configurable field of view, and
gameplay, audio and rendering fixes. All twelve campaign levels remain available.

## Play

**You need your own European Serious Sam Advance ROM. It is not included.**

1. Extract `ss-advance-v0.8.0-alpha.3-windows-x64.zip` into a writable folder.
2. Put your ROM at `orig/SSA.gba`.
3. Run `play-native.cmd`. No compiler, Vulkan SDK or emulator is needed.

Keep `save.dat`, `settings.dat` and `scores.dat` when updating. Existing settings
and unlocks are retained. The supported ROM's SHA-1 is
`4ff48d8c18b70a5184758f1917343ae85a70858e`.

## New since Alpha 2

- **Vulkan renderer:** hardware rendering for the world, sprites and reflections.
  Vulkan is the default for fresh settings and Clear Data. If unavailable or a
  render fails, the game falls back to Software and hides Vulkan from the choices.
  Existing saved renderer choices are preserved; select Vulkan in Graphics to
  try it on an upgraded installation.
- **Rendering optimizations:** cached GPU readback, parallel surface processing,
  combined depth/effects passes, and fewer redundant buffer clears. The latest
  refactor reduced median isolated render time by 21–30% in four 1080p scenes
  on an RTX 4060 Laptop GPU, with identical captured outputs. This is a local
  render benchmark, not a guarantee of gameplay FPS on other machines.
- **Visual fixes:** stable sprite priority in Vulkan, full-resolution half-alpha
  water reflections, and a background that retains its original scale at any FOV.
- **Graphics and controls:** a dedicated Graphics menu contains Display Mode,
  Renderer and Aspect Ratio. Settings includes Language and a 60–120° FOV slider
  (default 70°). Vertical aim is toggleable in Extras and defaults On; turning it
  off uses GBA-style aiming and autoaim. GBA mode keeps its fixed FOV and aspect.
- **Pickups:** collect ammo before owning its weapon, and pick up duplicate
  weapons even with full ammo, in both weapon modes.
- **Prion combat:** affected enemies can exchange melee attacks with other
  enemies, prefer nearby ranged opportunities and chase less. Conversion doubles
  remaining health once. Enemy-versus-enemy melee damage is halved and other
  damage doubled when a converted enemy is involved; player damage is unchanged.
- **Boss projectiles:** bosses no longer collide with or damage themselves with
  their own projectiles, including split projectiles and explosions.
- **Audio and menus:** enemy sounds carry farther, including kamikaze screams.
  Fresh settings use 80% music and 100% sounds. Settings, Graphics and Extras
  have updated organization and grid spacing.

Vulkan requires a compatible graphics driver. Software and GBA remain available.
Original and Classic HUDs work with all three renderers. Jump, Alternate weapons,
Automap, Weapon bobbing, Surface decals and Water reflections default Off;
third-person, in-game NETRICSA and vertical aim default On. Existing choices win.

## Controls

| Control | Action |
| --- | --- |
| WASD | Move |
| Mouse / left-click | Look / fire |
| E | Use |
| 1–0 / mouse wheel | Select weapon |
| Q | Previous weapon |
| R | Reload Colts with Alternate weapons enabled |
| Space | Jump, when enabled in Extras |
| H | Toggle third-person, when enabled |
| Tab / N | Toggle NETRICSA |
| M | Toggle automap, when enabled |
| + / − / mouse wheel in automap | Zoom |
| Esc / P | Pause / resume |
| F11 | Toggle fullscreen / windowed |

Original, optional SoundFont and Windows MIDI music are selectable when available.
SoundFont banks are not included; see `soundfonts/README.md` for setup.

## Known limitations and validation

This is still an alpha. Multiplayer is not playable and original-game parity
is still being refined. Saves retain unlocks, settings and scores, not a
mid-level position. Vulkan still uses CPU composition and frame readback;
full-resolution reflections remain demanding.

Validation covers focused rendering, HUD, settings, saves and audio checks;
Vulkan validation and sprite ordering; Prion and boss combat regressions;
website checks and packaged launch tests. All campaign levels are available
for manual playtesting; no new campaign playthrough is claimed.
