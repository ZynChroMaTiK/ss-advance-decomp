# Serious Sam Advance v0.8.0 Alpha 1

A playable native Windows x64 port, with all twelve campaign levels enabled.
Original feature and behavior parity remains in progress; this is an alpha prerelease.

## Play

1. Download `ss-advance-v0.8.0-alpha.1-windows-x64.zip` and extract it to a writable folder.
2. Place your own legally obtained Serious Sam Advance ROM at `orig/SSA.gba`.
   Supported ROM SHA-1: `4ff48d8c18b70a5184758f1917343ae85a70858e`.
3. Run `play-native.cmd`. No compiler or emulator is required.

The ZIP includes a statically linked C runtime. ROMs, personal saves/settings and
SoundFont banks are not bundled. Keep existing `save.dat` and `settings.dat` when
updating. The included SHA-256 checksum file verifies the download.

## Included

- All twelve Egypt/Rome campaign levels, including Caesar's Palace, with ordinary
  unlocks, saved progress, level selection and original password starts.
- Native enemies, weapons, combat, pickups, hazards, scripted encounters and doors.
- Keyboard/mouse controls, free look, jump, third-person H view, scalable software
  rendering and a selectable original-resolution GBA renderer.
- Title/menu flows, pre-level map views, NETRICSA briefings and an in-game Tab/N
  overlay, chapter introductions, ending, pause/quit confirmation and timed
  completion bonuses with campaign-session totals.
- Original ROM audio, optional hybrid SoundFont music and Windows GS MIDI music;
  independent music/effects volume, fullscreen/windowed settings and Extras toggles.
- Optional alternate Colts and double-shotgun behavior, plus current projectile,
  converted-enemy targeting, HUD and collision fixes.

SoundFont appears only after a bank loads successfully. Run the included
`scripts/install-soundfont.ps1` to obtain the optional SC-55 bank, or launch with
`--soundfont "path\bank.sf2"`. MIDI appears only if the named Windows GS device opens.

## Controls

WASD moves; mouse looks; left-click fires; E interacts; Space jumps; H switches
view. Number keys 1–0 / mouse wheel select weapons; Q recalls the previous weapon.
Tab/N opens NETRICSA; Esc/P pauses; R restarts the level. Extras can disable jump,
third-person and the in-game NETRICSA overlay. Alternate weapons default to Off.

## Known limitations

- High-score lists/name entry, remaining presentation/timing parity and audio
  fidelity still need work. Playable multiplayer is not implemented.
- All twelve levels are available for manual validation. Earlier automated checks
  covered an eleven-level chain and a separate final-map completion; this release
  does not claim a newly validated full twelve-level playthrough.
- Campaign-session totals are not a new mid-level disk-save system.

Build and startup/restart checks cover both renderers. This release does not change
the original ROM. The browser atlas and 3D explorer are separate exploration tools.
