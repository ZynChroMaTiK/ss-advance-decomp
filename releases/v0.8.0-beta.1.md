# Serious Sam Advance v0.8.0 Beta 1

The native Windows port enters beta with all twelve campaign levels, keyboard
and mouse controls, and optional PC features. This release adds Vulkan image
effects, a revised Classic HUD crosshair, combat improvements and rendering
optimizations. Multiplayer is still unavailable, and original-game parity
continues to be refined.

## Play

**You need your own European Serious Sam Advance ROM. It is not included.**

1. Extract `ss-advance-v0.8.0-beta.1-windows-x64.zip` into a writable folder.
2. Put your ROM at `orig/SSA.gba`.
3. Run `play-native.cmd`. No compiler, Vulkan SDK or emulator is needed.

Keep `save.dat`, `settings.dat` and `scores.dat` when updating. Saved settings,
unlocks and scores are retained. The supported ROM's SHA-1 is
`4ff48d8c18b70a5184758f1917343ae85a70858e`.

## New since Alpha 4

- **Vulkan graphics options:** optional antialiasing, sharp anisotropic texture
  filtering, world-texel ambient occlusion and camera motion blur. Motion blur
  affects the scene while weapons, crosshair and HUD stay sharp. All four
  effects default Off and are disabled outside Vulkan.
- **VSync:** a saved Graphics option for all three renderers when Windows
  compositor synchronization is available. Defaults On for fresh settings and
  older saves that predate the option. An existing saved VSync choice is retained.
- **Rendering optimizations:** GPU-retained effect data reduces transfers;
  stationary frames skip unnecessary motion-blur work, and combined effects
  reuse working buffers. A stationary-camera 1080p diagnostic measured about
  8% lower render time with motion blur on an RTX 4060 Laptop GPU. This is an
  isolated renderer result, not a gameplay FPS guarantee.
- **Classic HUD:** a custom centered crosshair uses green/yellow/red target-health
  feedback with shaded palette details. The notification now reads "Analyzing".
- **Combat:** doubled chainsaw damage; Time Strike plays its impact sound when
  falling objects hit the floor. Normal enemies no longer melee Prion-converted
  enemies; converted enemies can still melee others, and melee hits still cause
  flinching. UMT is now last in weapon order, after Cannon: Time Strike uses 8,
  Cannon 9 and UMT 0.
- **Menus and settings:** "Alternate weapons" is now **Enhanced weapons**.
  Graphics groups display options, filtering/effects and scene details. Volume
  controls have more space, and non-audio settings no longer reapply audio.
- **Website:** updated release information and weapon/NETRICSA references.

## Still included

- All twelve Egypt and Rome campaign levels, original weapons, enemies and music.
- Keyboard/mouse controls, adjustable FOV and sensitivity, optional jumping,
  third-person view and enhanced Colts/double-shotgun behavior.
- Original and Classic HUDs, in-game NETRICSA and an optional zoomable automap.
- Vulkan, Software and GBA rendering; optional water reflections, decals,
  godrays, sprite shadows and weapon bobbing.
- Original, optional SoundFont and Windows MIDI music.
- Saved level unlocks, high scores, original passwords, finite lives and retries.

Vulkan remains the default where available, with automatic Software fallback.
VSync, mipmapping, vertical aim, third-person and in-game NETRICSA default On.
Jump, Automap, Enhanced weapons, weapon bobbing and optional visual effects
remain Off by default. Existing saved choices take precedence.

## Controls

| Control | Action |
| --- | --- |
| WASD | Move |
| Mouse / left-click | Look / fire |
| E | Use |
| 1?0 / mouse wheel | Select weapon |
| Q | Previous weapon |
| R | Reload Colts with Enhanced weapons enabled |
| Space | Jump, when enabled |
| H | Toggle third-person, when enabled |
| Tab / N | Toggle NETRICSA |
| M | Toggle automap, when enabled |
| + / ? / mouse wheel in automap | Zoom |
| Esc / P | Pause / resume |
| F11 | Toggle fullscreen / windowed |

## Known limitations and validation

This is a beta, not a finished parity release. Multiplayer is not playable.
Saves retain progress, settings and scores, not a mid-level position. Vulkan
still uses CPU composition and readback; full-resolution reflections and optional
effects can be demanding. Motion blur follows camera movement, not independent
object velocity. VSync uses the shared Windows presentation path; switching it
Off removes the application's wait, not Windows desktop composition.

Focused native, Vulkan, Windows input/settings/audio and sanitizer checks pass.
Release checks include the packaged executable/launcher and website. All twelve
campaign levels remain available for manual validation; no new full campaign
playthrough is claimed. SoundFont banks and ROMs are not bundled.
