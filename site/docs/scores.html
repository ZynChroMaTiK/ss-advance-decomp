Original Scores viewer

Name entry and saved records

The native port now also recovers original 08016F70 ranking and 08016F98 name entry. The editor keeps the original12slots, character cycling, repeat delay/wrap, selected-glyph colors and underscore-to-space conversion. B/Esc does not discard a qualifying record, as in the original. A tie inserts before the existing equal score. The first editor tick shifts entries to reserve the slot; confirmation commits the score/name, highlights it and scrolls to its six-entry group. Only the submitted event is persisted; the intermediate editor table is never flushed. Nonqualifying scores return to Main. The PC extension accepts typed letters/digits/spaces, Backspace, Delete, Home/End and cursor movement; letters including WASD/M do not navigate or mute.

The frontend offers this flow after confirmed Pause Quit and after the campaign ending. Quit uses the current run score; the ending uses the final bonus-adjusted score. The following New Game/password/selected start clears completion latches and session totals, preserving stored records. The latest user correction returns directly to Main after death without restart input or name entry; see run-exit.md.

scores.dat is a separate320-byte, version1, little-endian CRC32 file. It stores 18score/name records plus the last entered name. Existing16-byte save.dat and settings.dat remain compatible. Custom --save-file PATH uses PATH.scores. Missing/corrupt files use ROM defaults without writing during load. A submitted record merges against the latest file under an exclusive lock, then flushes and atomically replaces it. Failed writes retain the record for the current session and show a notice. An explicit submission can replace a corrupt file. Confirmed Clear Data resets scores, progress, language and settings; cancelling retains them.

Viewer recovery history

Main → Scores now runs a native reconstruction of original 0801737C rather than reporting an unsupported destination. It uses the original 18 seeded records initialized by original 08015530: scores from 0x44C144 and names through the pointer table at 0x44C18C, each a four-byte score and twelve-byte name. The ROM's name templates have placeholder scores; they are not a populated list. The three localized headings are original text entries247..249. All artwork, font metrics, palette choices and background layers are shared with the menu.

The initial scroll begins at160 pixels. The three group stops are16,−160 and −336 pixels; entrance and page movement advance two pixels per60Hz tick. Page changes are admitted only at a stop. Up/Down changes group, with no wrap. Original arrow indicators blink on counter bit32. Enter or Esc plays command16 and leaves on the following tick. Mouse clicks on the upper/lower arrow areas change group; a click in the middle leaves. Menus retain the existing music sequence and freeze gameplay.

It compares viewer state, ordered sound commands, glyph submissions and composed pixels in all3languages, after executing the actual original default-score initialization loop, including the entrance, endpoint inputs, moving inputs, forward/backward pages and exit.
