Optional vertical aiming, 2026-10-20

Options > Extras includes Vertical aim, On by default. English, German and French labels use the existing one-tile spacing. Keyboard arrows, confirm and mouse selection cycle its value; settings persistence and Clear Data use the common field catalogue.

When Off, native software rendering and GBA rendering use the same original auto-aim queries, slope, target and marker. Mouse yaw remains active; vertical mouse input is discarded before polling and cannot latch free aim. Applying the setting also clears accumulated pitch immediately. The camera stays level in first and third person, with the cursor projected onto the auto-aimed shot using a non-bobbing eye. Native cursor projection uses the software renderer's focal length; GBA retains its original reciprocal-table projection. Rendering resolution, aspect ratio, jump and HUD selection remain independent.

When On, software rendering retains its existing vertical mouse aiming and third-person camera convergence. GBA always uses original aiming, even with the preference On. No original weapon controller or auto-aim routine changed.

Settings v13 keeps the16-byte disk size and all previous payload bit positions. Byte7, formerly the signature terminator, stores bit0 for vertical aim. Its other bits are reserved and rejected. The seven-byte signature remains SSA-OPT, with CRC coverage unchanged. v1..12 files require byte7 zero and load with the new preference On while retaining their existing choices. Existing v13 files retain their explicit On/Off choice. Fresh settings and Clear Data use On, following the user's updated default preference.
