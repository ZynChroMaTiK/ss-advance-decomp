Serious Sam Advance - playable native prototype

Project website, features and roadmap · Combined 2D atlas / 3D level browser

Build from a fresh checkout

Install Visual Studio 2022 Build Tools with the C++ desktop workload and CMake tools. Clone this repository, open PowerShell in its folder, and run:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1

Compilation does not require a ROM. To play, place your own game ROM at orig/SSA.gba, then run play-native.cmd. The launcher uses build/native-windows/Release/ssa_native_game.exe; build it first. The first ten campaign levels are supported; the final two remain unavailable.

The repository includes native source, Windows frontend, tests, scripts, research, recovered C and the complete static website. ROMs, saves, generated assembly, toolchains, dependency checkouts and local server databases stay local. See preserved recovery sources for the exact C export and sanitized candidate/attempt/note history. GitHub Pages publishes only site/; source additions do not change its URL.

Optional original-ROM timing tests use a pinned test-only mGBA checkout:

git clone https://github.com/mgba-emu/mgba tools/mgba-timing
git -C tools/mgba-timing checkout --detach 26b7884bc25a5933960f3cdcd98bac1ae14d42e2

The native game does not link against mGBA. Decompilation tooling is provisioned separately by scripts/bootstrap.sh under WSL/Ubuntu; see the setup below.

Current prototype

The first ten levels are playable natively on Windows. Run play-native.cmd to use your supplied orig/SSA.gba. This build includes actual enemy AI, weapon firing, damage/death, pickups, scripted waves, doors, the exit, and restart, with the original world, actors, HUD and weapon graphics. Time Strike targets now keep a valid rendered frame if their controller changes animation while frozen, preventing a reference-renderer failure during combat. Health, armor and boss bars now use the original scanline palette colors, including the original health-above100 variation. Player collision now detects large enemies before Sam enters their bodies. If a scripted spawn already overlaps Sam, movement away can free him while walls and other enemies still block him. Startup goes straight to the title screen. Options includes a Language row: Enter, click or Right cycles English/German/French; Left cycles backward. Language and beaten levels persist in save.dat beside this launcher. Single Player has New Game, Select Level, Password. Level 1 is always unlocked; beating a level unlocks its successor on any difficulty. Select Level uses the original localized campaign names, shows locked levels with padlocks, and omits multiplayer maps. Egypt and Rome each have a page of six levels, shown without number prefixes. Use Up/Down to select a level or Left/Right/the arrows to switch chapters. The final two campaign maps remain marked unavailable until supported by the port. Selected levels use their original starting weapons and ammo after choosing difficulty. Options → Clear Data resets progress and language after a Yes/No warning; No is selected by default, and Esc cancels. New Game keeps existing unlocks. See saved data and level selection. The original background grid appears from the first title/main-menu visit. Choose Single Player, New Game and a difficulty to begin. Use arrows or WASD, Enter/Space to confirm, or hover and click a menu entry. Esc goes back. Mouse selection plays the original cycling sound only when the highlighted item changes. The title music continues after Press Start without restarting. Options → Credits now shows the original scrolling credits. Hold Up/W to pause or Down/S to speed up; Enter/Space/click or Esc returns to Options. Single Player → Password now restores original starting weapons and ammunition for the ten supported maps. Type the password directly (case-insensitive), with or without its trailing underscore placeholders; use Backspace/Delete to correct it, and Enter or a click to submit. Left/Right moves the cursor; Up/Down retains the original character cycling. Esc goes back. Passwords select difficulty too. Fresh --level launches use that map's original starting weapons and ammo. Advancing from a previous level keeps your carried weapons and ammunition. Original ROM sound effects and level music now play through a native audio mixer. The overall soundtrack plays at50% of its previous amplitude so effects stand out. Audio buffers refill on device events, keeping music at normal speed when the mouse and UI are idle. Footsteps follow grounded movement in both views without interrupting the music. Tommy gun fires about 8.53 times per second. Chainsaw uses the measured original GBA average of about 8.69 attacks per second, with increased 192-unit PC reach. The minigun also uses its measured original GBA cadence, about 8.53 rounds per second, with its existing damage per round. Chainsaw bites accumulate damage between attacks so they also hurt enemies on Hard. Special weapons 8 and 9 now fire natively: the area blast and targeted falling effect include their original background-palette flashes. Hurt flashes expire, allowing later hits to play the hurt sound again. Time Strike falls at the measured original GBA update rate and retains original damage, including tougher enemies surviving. Empty space, items, corpses and temporarily protected enemies consume no Time Strike ammo and play no firing sound. These attempts still play the weapon's firing gesture. Falling objects move smoothly between physics updates, preserving their landing and damage timing. Aim, movement and release remain responsive at 60 Hz. Continuous weapon loops stop on release, switching, empty ammo, pause or focus loss; the minigun keeps its wind-down sound. See weapon fixes. Prion gun shots now start on the aim line and fly independently immediately, like the corrected rocket launcher, without following later mouse movement. Prion-affected enemies run their behavior and animation at twice normal speed. Quick fire clicks stay pending until the first shot, even if released during weapon startup, raising or reload. Holding fire keeps the same firing rate. World and enemy sounds pan left/right and fade with three-dimensional distance from Sam. Doors use the same smooth falloff as enemies, getting quieter as you move away even at close range. Pickups play locally like player sounds, without distance attenuation or positional panning. Door loops stop when each door stops; multiple enemies can sound at once, with moving sounds following their own source. The third-person camera keeps the same audio listener as first person. Before every level start/restart, the original map view plays its start music. Click or press Space/Enter to leave the map; it fades to solid black, pauses, then gradually reveals the level with its soundtrack. The weapon is visible from the start of the reveal. Movement, aiming and the live HUD are active during it. Death and level completion select their original music cues. Old effect loops stop on the end screens. Instrument note tails now follow the ROM's echo settings. Music and effects use separate voices, so weapons, enemies and footsteps can play together without cutting off the soundtrack. Player pickups, weapons and hurt sounds take priority over enemy/world effects when sound pools or output headroom fill up. Each music track plays one note at a time; repeated effects can overlap. Sampled instruments and effects receive a 6 dB PC volume boost to improve their balance against PSG channels. World, player and enemy effects receive an additional 50% boost with peak protection. Wave instruments also use the original lower octave and stepped volume conversion. Single-player Sam uses the original white-shirt variant. Enemies slide around one another in crowds and gradually separate overlapping spawns, while keeping walls, doors and the player solid. Gunrilla cannonballs clear their shooter's collision bounds before normal collision with that shooter resumes; walls, players and other enemies still block them.

Click to capture the mouse. WASD moves, mouse turns, left mouse fires, Space jumps, H toggles first/third person, E uses doors, and 1–0 selects owned weapons. Mouse wheel up selects the previous usable weapon; down selects the next. Cycling wraps around and skips unowned or empty weapons. Q swaps to the last equipped weapon. Weapon changes wait until the current firing/reload animation ends; automatic weapons finish the current animation cycle. Buttons activate immediately on E, without waiting for the weapon to finish lowering. Esc releases the mouse; R restarts from the current level's entry state. Enter advances from supported intermediate levels with your health, armor, weapons, ammo and score. At the last supported level, Enter replays it. Press M to mute/unmute audio. Use play-native.cmd --no-music for effects only, or play-native.cmd --mute to start silently. Mouse look turns and aims vertically through 80 degrees up or down, with perspective-correct world rendering. The sky stays flat and perpendicular to the view, with horizontal panorama scrolling. At level aim its artwork fills the top three quarters. Looking up or down shifts the image vertically, extending each column's top/bottom edge pixel into exposed space. At level aim, the H camera sits 256 units behind the player with a 64-unit height bias. It orbits with mouse pitch and points along a common sight ray, keeping the original crosshair aligned; walls and ceilings retract the camera. Switching to the chainsaw keeps the same camera angle as ranged weapons. Weapon muzzle flashes are hidden in third-person view and visible in first person. Ranged weapons have no distance cutoff; shots stop at obstructions or the map boundary. Player projectiles continue until impact. Rockets follow their launch direction immediately, independently of later mouse turns or player movement. The chainsaw remains a melee weapon with a 192-unit trace, twice the ROM's 96. The original crosshair artwork and behavior are restored. Rendering now caches static geometry and presents completed frames offscreen to reduce black flicker. If launching fails, the launcher keeps the error visible and saves a separate session log under build/logs/. It also updates build/logs/last-launch.log when available. Multiple game sessions can launch concurrently.

Rendering now follows the window size automatically. Resize/maximize for more world detail, or run play-native.cmd --resolution 3840x2160 for a fixed size. Arbitrary dimensions are supported within memory and platform limits; this renders new world samples. --original-renderer restores the 240×160 reference view. See render settings.

The updated normal-input campaign run completes ten consecutive maps in 117,841 frames, ending with1,390,000 total score and33 health, carrying only earned inventory between maps. It covers pickup-triggered doors, wall switches, elevated enemies, the first boss, Prion conversion, Time Strike and the real exits. GCC ASan/UBSan with leak detection and Windows MSVC agree on every result. Converted enemies can now fire safely after their previous target's actor slot has been cleared or reused, preserving the original slot behavior. See playable build details. Original feature and behavior parity is the completion target, alongside the explicitly requested PC controls and rendering changes. The remaining campaign, boss-level progression, remaining original menus/presentation effects remain unfinished. Audio fidelity is still being refined; see audio integration. See special weapons and palette recovery for the new integration checks and remaining presentation limits. The native effect runtime now also supports original type-64 wall/sector clipping and relocation; see recovery and checks.

The separate run-native-viewer.cmd [--level 0..15] remains a diagnostic map viewer with idle objects; it is not the playable build.

Reproduce the setup

Requires Ubuntu in WSL, Git, GCC, and uv. In Ubuntu, from this repository:

bash scripts/bootstrap.sh
.venv-linux/bin/python scripts/decomp.py import --own-copy
.venv-linux/bin/python scripts/decomp.py autopilot
.venv-linux/bin/python scripts/decomp.py export

Place your own ROM at orig/SSA.gba. The ownership flag confirms that copy is legally obtained. ROMs and generated ROM-derived assembly stay out of Git. The importer deliberately uses conservative discovery; broad speculative scans of this ROM proposed thousands of unverified starts in asset data.

Build the portable native libraries under Ubuntu:

.venv-linux/bin/cmake -S . -B build/native
.venv-linux/bin/cmake --build build/native

Build all native Windows libraries with the installed Visual Studio 2022 BuildTools, using its bundled CMake:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1
# Also run the hidden-window input test:
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -TestInput

Output is build/native-windows/Release/, including the playable ssa_native_game.exe, static libraries, diagnostic viewer and validation tools.
