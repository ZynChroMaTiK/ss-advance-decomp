Native campaign story controller

campaign_story.c recovers the original campaign panel script19458, moving panel sprites193D8 and input/text-scroll wrapper1965C. The eight records at 0844CFC4 are copied from the user's ROM as data. Original197B0 chooses record0 at level0 (three Egypt panels), record4 at level6 (one Rome panel), and record6 at level12 (one ending panel); records3/5/7 are sentinels.

The six script stages retain entrance motion, strict endpoint tests, wait120+180, scrolling, wait120+300 and exit motion. Position arithmetic wraps32; sprite coordinates use signed high halfwords and clamp independently for each of the four64x64 panels. A changed image transfers only after all four positions update. Text changes reset scroll before requesting its initial rows. Scrolling retains the original signed high-half clamp and21-row ring updates.

Processed input10000 requests skip command13, marks mode1 and requests sound fade7 only when music is enabled. Its remaining input is cleared for that call. Up40 pauses scrolling and suppresses skip-wait800000; Down80 accelerates4x. The script still ages holds while scrolling is paused. Calls during outer fade modes1/2 continue updating image motion and text, without repeating skip.

The API rejects unsupported starting levels, malformed metadata, invalid state and callback reentry. Presentation callbacks observe committed prefix effects; failures preserve those effects and release the update guard. This controller does not own artwork, text formatting, audio playback or the outer dispatcher. The new campaign_screen.c supplies that presentation composition and now runs in the Windows frontend. Score/name entry and the original completion tally UI remain separate unfinished work.

Native screen and Windows integration

New Game now shows the three original Egypt panels before its map. Advancing from map5 to map6 shows the Rome panel before the next map. Password/selected level starts and R restart bypass chapter stories, preserving the original 19268 skip gate. After the final level, Enter shows the ending panel and then returns to Main; R still replays the level. Completion still uses the existing Enter shortcut rather than the recovered timed score/tally screen.

Returning from an ending now allows a fresh New Game; the frontend rebuilds the original level0 state rather than retaining the final level's game object. Saved language/unlocks remain intact.
