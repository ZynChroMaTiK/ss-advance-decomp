Native field of view, 2026-10-20

Settings places Field of view beneath Aspect ratio. Its slider covers60..120 degrees, in one-degree keyboard steps, with direct mouse adjustment. The default is70 degrees, preserving the previous native projection exactly. The definition is horizontal FOV at3:2; vertical framing remains constant across aspect ratios, so wider displays show more horizontally. GBA mode dims/skips both Aspect ratio and FOV, preserving the saved native value for a later renderer switch.

The original focal distance was height*(0x55b05a/65536)/80. At3:2 this is 70.00000447 degrees horizontally. The default explicitly retains scale1; other choices multiply focal distance by tan(35 degrees)/tan(FOV/2). World walls/planes, projected actors, pitched views, water reflection scenes and native auto-aim cursor projection share this scale. The flat background retains the original70-degree horizontal sampling and pitch shift at every FOV, including the mirrored scene and Vulkan background pass. Its established three-quarter vertical coverage and edge fills remain intact. HUD and first-person weapon artwork retain their existing size and placement. GBA reflected geometry always uses scale1.

Settings v14 keeps the16-byte format and existing CRC coverage. Byte7 bit0 remains vertical aim; bits1..6 encode the FOV offset above60, with61..63 rejected. Bit7 is reserved and rejected. All versions1..13 load with70-degree FOV, while their other settings remain intact. Clear Data restores70. The field catalogue and central native application handle validation, comparison and live changes.

The current Settings layout remains on the eight-pixel grid: Language/FOV/ Music style/Music volume/Sounds volume labels at Y24/48/80/96/120; FOV/music/sounds bars at Y56/104/128; Back remains at Y144. English, German and French screenshots were inspected for overlap/clipping.

Validation: static Windows build and eight focused CTest checks passed. Renderer checks exercise flat and pitched views at60/120 and exact pixel restoration at70. The reflection test checks endpoint projection changes, default pixel restoration, and unchanged GBA output at120. Auto-aim cursor tests pass at both endpoints in first/third person with192 bob phases each; maximum error is below0.004 GBA pixels. Codec tests cover all61 values, reserved bits and v12/v13 migration. Menu tests cover keyboard clamps, mouse endpoints and midpoint, the disabled GBA row, localization and live Windows persistence. No campaign playthrough was run.

The background regression compares common visible sky pixels at60/90/120 against 70 degrees, at3:2 and widescreen sizes, with level/up/down views and differing headings. Existing checks still require world projection to change with FOV and the exact original image to return at70.
