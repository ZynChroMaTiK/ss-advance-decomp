Optional Classic HUD

Options -> Extras -> HUD cycles Original / Classic with Left/Right, Enter or a mouse click. Original remains the default. The choice applies immediately and persists through the existing CRC-protected settings file. Version8 uses byte11 bit7 for HUD style and its lower seven bits for sound volume; all version1..7 files load as Original without losing other preferences. Automap and Jump remain Off by default. Clear Data restores those defaults.

Original HUD preserves the original GBA constructor/controller coordinates and transparent sprite padding: lives top-left, weapon icon top-right, score/clock top-center, status bottom-left and ammo bottom-right. No margin normalization or rearrangement applies to its240x160 OAM. Software rendering anchors those same groups to the viewport, preserving their native distance from each edge. The Serious Engine positioning below describes Classic only.

Fixed crosshair (2026-10-22)

Classic uses the user's exact19x19 crosshair.png, padded into24x24 storage without resizing, pixel filtering or generated shading. Its isolated center dot at(12,12) stays exactly on the aim coordinate. The original light/dark OBJ81/206 colors and binary transparency match the PNG pixel for pixel without a target. Original HUD retains both original crosshair animations. Classic replaces type18 only in presentation OAM; its original controller and weapon/target behavior remain intact.

The color thresholds follow Croteam's PlayerWeapons.es RenderCrosshair: Serious Engine source. A living enemy is green at>=60% nominal species health, yellow at25..59%, red below25%; no enemy, pickups, obstructions and corpses use white. Prion health above the original species maximum stays green. The existing original activation table supplies nominal maxima without a duplicate health table.

View preparation samples the existing dedicated unlimited sight trace, with no combat callbacks or gameplay-query changes. Native vertical aim stays centered; GBA and native autoaim use the existing unbobbing projected cursor, including the third-person correction. Classic shows the fixed crosshair for every weapon. A separate center-anchored layer avoids accidental corner anchoring when autoaim moves the cursor over other HUD rows. The GBA RGB555 and Software/Vulkan RGB888 compositors share the art/palette helper. Death, automap and suppressed HUD hide it.

Focused checks cover exact25/60% boundaries, unchanged shape, palette colors, real-world target/dead-target/obstruction queries, all aiming policies, GBA/native composition, aspect-ratio anchoring and original-HUD restoration. These are focused renderer checks, not a campaign playthrough.
