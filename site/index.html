DOWNLOAD & HELP

Download the game.
Here’s how to start.

Grab the Windows download and follow the three steps below. You won’t need an emulator or build tools. If you’d like to work on the port, you can find the code on GitHub.

v0.8.0 ALPHA 1 / WINDOWS 64-BIT

Getting started

You’ll need your own European version of the Serious Sam Advance ROM. A ROM is a file containing the original GBA game. Other regional versions won’t work. The download doesn’t include a ROM.

  1. Download the Windows ZIP and extract it to a folder such as Games.
  2. Rename your European ROM to SSA.gba and put it in the orig folder.
  3. Double-click play-native.cmd to play.

Updating? Keep save.dat and settings.dat so you don’t lose your unlocks or settings. Extra music files are optional.

WORKING ON THE CODE

Want to build it yourself?

If you’d like to change the game or build it yourself, start here.

Show build instructions
  1. Install Git for Windows and Visual Studio 2022 Build Tools with the C++ desktop workload and CMake tools.
  2. Clone the project and enter its folder:
    git clone https://github.com/ZynChroMaTiK/ss-advance-decomp.git
cd ss-advance-decomp
  3. Build the game:
    powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1
  4. Place your own European game ROM at orig/SSA.gba, then run play-native.cmd.

You can build without a ROM. You need the European ROM to play or compare behavior with the original game.

HOW WE CHECK OUR WORK

Checking against the GBA game

We compare the port with the original game and test how its parts work together. That helps us catch things like weapons firing differently, doors not opening or progress getting stuck.

Earlier tests finished eleven levels in a row and the final level separately. If you play through this version and something goes wrong, a bug report would help.
