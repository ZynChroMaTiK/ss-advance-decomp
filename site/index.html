SOURCE AVAILABLE / NATIVE WINDOWS BUILD

Build it.
Help bring it home.

The repository contains the native runtime, Windows frontend, recovery sources, tests, research and this website. Game logic runs natively; the original ROM supplies asset data.

GET STARTED / WINDOWS

From source to Sam.

  1. Install Visual Studio 2022 Build Tools with the C++ desktop workload and CMake tools.
  2. Clone the project and enter its folder:
    git clone https://github.com/ZynChroMaTiK/ss-advance-decomp.git
cd ss-advance-decomp
  3. Build the native executable:
    powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1
  4. Place your own game ROM at orig/SSA.gba, then run play-native.cmd.

The ROM is needed to play and run original-routine comparisons; compilation does not require it.

Behavior before assumptions.

Recovered routines are compared against the original ROM. Native integration checks cover real maps, ownership, callbacks, progression, and memory safety.
