RECOVER · VERIFY · REBUILD

Built from the original.
Moving forward, natively.

A native PC reconstruction of Serious Sam Advance. Original content, behavior, progression, and timing are the target, alongside modern PC controls.

CURRENT MILESTONE

Ten levels. Native Windows.

The prototype includes enemy AI, combat, weapons, pickups, scripted waves, doors, original graphics, and a native audio mixer. Keyboard and mouse controls add jumping and a third-person toggle.

The final two campaign maps and full original parity remain unfinished. Atlas coverage includes all twelve campaign maps and four multiplayer arenas.

Read the native game findings →
VERIFICATION

Behavior before assumptions.

Recovered routines are compared against the original ROM. Native integration checks cover real maps, ownership, callbacks, progression, and memory safety.

The current ten-level normal-input campaign chain completes in 117,841 frames; GCC sanitizer and Windows MSVC runs agree on the results.
