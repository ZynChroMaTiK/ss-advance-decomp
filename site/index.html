Choose a result, then press Enter or Show on map. If it is hidden, turn on its checkbox below.

Drag to rotate the map and scroll to zoom. On a touchscreen, use two fingers to move or zoom. With the view selected, arrow keys move the map; Shift + arrows rotate it. In Free flight, drag to look and use WASD to move, Q/E to go down/up, or hold the on-screen buttons. Press Esc to return.

Hide ceilings to see inside rooms. Green areas show where walking into a room starts an event; select one to learn more. This is a map viewer, not the game: enemies do not move and lifts do not run. Show doors open lets you see beyond closed doors.

DOWNLOAD & HELP

Play the alpha.
Help bring it home.

Download the game below and follow the setup steps. You do not need an emulator or programming tools to play. If you want to help with the project, the source code is on GitHub.

v0.8.0 ALPHA 1 / WINDOWS 64-BIT

Download and play.

You need your own European version of the Serious Sam Advance ROM. A ROM is a file containing the original GBA game. Other regional versions are not supported, and no ROM is included.

  1. Download the Windows ZIP and extract it to a folder such as Games.
  2. Rename your European ROM to SSA.gba and put it in the orig folder.
  3. Double-click play-native.cmd to play.

Updating? Keep save.dat and settings.dat to retain your unlocks and settings. Extra music files are optional.

FOR CONTRIBUTORS

Want to build it yourself?

Most players can use the download above. These steps are for people who want to compile or change the game.

Show build instructions
  1. Install Git for Windows and Visual Studio 2022 Build Tools with the C++ desktop workload and CMake tools.
  2. Clone the project and enter its folder:
    git clone https://github.com/ZynChroMaTiK/ss-advance-decomp.git
cd ss-advance-decomp
  3. Build the game:
    powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1
  4. Place your own European game ROM at orig/SSA.gba, then run play-native.cmd.

You can build without a ROM. You need the European ROM to play or compare behavior with the original game.

HOW WE CHECK OUR WORK

Keeping the original feel.

We compare the port with the original game and test how its parts work together. That helps us catch things like weapons firing differently, doors not opening or progress getting stuck.

Earlier tests finished eleven levels in a row and the final level separately. Those checks are useful, but we still need people to play through the current version and report what goes wrong.
