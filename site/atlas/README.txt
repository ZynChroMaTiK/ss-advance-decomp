Serious Sam Advance map guide

Open index.html, pick a level and have a look around. All 16 original maps
are here. They work offline, and you won’t need a ROM to browse them.

GETTING AROUND
Choose a level, drag to move around, and scroll or use +/− to zoom.
Select an item, enemy, door or room for details. The arrow keys move the map;
Home fits it to the window. Use Details search to find something by name.

Use Layers to show or hide items, enemies and the areas that start events.
An asterisk (*) means an item or enemy appears later in the level. They will
not all be present at once. Doors show how they start; they can change later.

SECRETS AND MAP SYMBOLS
Five known secrets are marked in levels 1–5. Select a pink secret marker for
directions and a walkthrough link. There may be more to find.
Open Map guide for the full symbol key. Red floors mark deadly surfaces or pits.
H100 adds 100 health when you have less than 200, with no cap on the result.

FILES
png/ contains maps ready to view or print. svg/ contains zoomable versions.
data/ contains map details for research. manifest-sha256.json lists checksums
for checking the files. The icons and backgrounds use original game artwork.

ABOUT THE PC GAME
Want to play as well? Download the Windows port below. You’ll need your own
European version of the Serious Sam Advance ROM. No ROM is included.
Download the port: https://github.com/ZynChroMaTiK/ss-advance-decomp/releases
Project website: https://zynchromatik.github.io/ss-advance-decomp/

EDITING THE MAP GUIDE
The map sources are scripts/export_topmaps.py and scripts/topmap_viewer.*.
Use scripts/refresh_atlas_ui.py to update the viewer from existing exports.
See site/README.md in the repository for website editing instructions.
