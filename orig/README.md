# Put your European game ROM here

To play, you need your own ROM of the **European version of Serious Sam Advance**.
Rename the file to **SSA.gba**, place it in this folder, then run
**play-native.cmd** from the main game folder.

Other regional versions are not supported. No ROM is included with this project.

If you need to check your file, the supported ROM's SHA-1 fingerprint is:
`4ff48d8c18b70a5184758f1917343ae85a70858e`.

The port reads the ROM for game data and does not change it. You do not need a
ROM just to compile the source code.
