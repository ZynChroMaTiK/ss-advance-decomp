# Put your European game ROM here

To play, you’ll need your own ROM of the **European version of Serious Sam Advance**.
Rename the file to **SSA.gba**, place it in this folder, then run
**play-native.cmd** from the main game folder.

Other regional versions won’t work. The download doesn’t include a ROM.

If the game won’t load your file, check the region and filename first. You can
also check it against this SHA-1 fingerprint:
`4ff48d8c18b70a5184758f1917343ae85a70858e`.

Your ROM stays unchanged. If you’re only building the code, you won’t need it yet.
